# @deepseek-ai/dsh-client-ui-trellis-knowledge

English | [中文](README.zh.md)

Transparent Trellis Knowledge Hub view: real-time document ledger, concept extraction network, evidence provenance, and full interactive Obsidian force-directed graph.

## Features

- Real-time Document Ledger displaying all stored knowledge documents, MarkItDown source extractions, summaries, and tags.
- Transparent Concept Relations and Evidence Network with grounded quotation quotes and confidence meters.
- Interactive Obsidian Force-Directed Knowledge Graph canvas with category color coding and pan/zoom controls.
- Slide-over Full Document Reader Drawer with extracted Markdown preview and one-click "Ask Agent" trigger.

## Model Experience

None, as this package is a browser-side UI view plugin and registers nothing model-facing.

#### KV Cache effect

None.

## Known Limitations and Deferred Work

- Graph rendering relies on HTML5 Canvas.
- Document previews display text and Markdown; binary attachments show metadata and source references.
