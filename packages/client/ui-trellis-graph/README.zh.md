# @deepseek-ai/dsh-client-ui-trellis-graph

[English](README.md) | 中文

DeepSeek Harness Web 客户端中用于展示 `trellis_graph` 工具调用结果的交互式图谱可视化组件。

## 功能特性

- 使用 `force-graph` 为 Trellis 知识文档与有向关系呈现力导向图布局。
- 交互式节点检查面板，展示文档摘要、标签、来源凭据、关联关系、证据片段与置信度。
- 当前图谱快照内的本地节点检索与过滤。
- 自适应缩放和点击聚焦居中交互。

## 模型体验

无，本包为浏览器端工具视图插件层，不注册任何面向模型的表面。

#### KV Cache 影响

无。

## 已知限制与后续规划

- 超过配置节点上限的大型图谱将呈现为有界局部邻域视图。
- 关系的建立通过 Agent 工具操作触发，暂不支持在画布上手势直接连线编辑。
